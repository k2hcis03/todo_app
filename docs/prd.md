# 할 일 관리 앱 PRD

## 1. why - 목적

- 일일 할 일을 주간 계획과 1년 목표에 연결해서 관리
- todo/doing/done 상태를 보드에서 드래그 앤 드롭으로 바꿈
- 주간 진행률을 직접 입력하지 않고 할 일 완료 상태에서 자동 계산

## 2. who - 타깃 사용자

- 1년 목표를 세우고 주간·일일 단위로 쪼개서 실행하는 개인 사용자
- 할 일 진행 상태를 한눈에 보고 싶은 사용자
- 주간 단위로 목표 달성률을 확인하고 싶은 사용자

## 3. User Flow

1. 1년 목표 생성
2. 1년 목표에 연결된 주간 계획 생성
3. 주간 계획에 연결된 일일 할 일 생성
4. 보드에서 할 일 확인 (todo / doing / done 컬럼)
5. 할 일을 드래그 앤 드롭해서 상태 변경
6. 주간 진행률 자동 갱신
7. 주간 진행률을 바탕으로 1년 목표 진행 상황 확인

## 4. 기능 요구 사항

### P0 - 핵심 기능

- **할 일 CRUD**
  - 생성: 제목, 날짜, 연결할 주간 계획
  - 조회: 일일 할 일 목록
  - 수정: 제목, 날짜, 연결된 주간 계획, 상태
  - 삭제
- **상태 관리**
  - 상태 값: `todo` / `doing` / `done`
  - 새로 만든 할 일은 `todo`
- **드래그 앤 드롭 상태 변경**
  - 보드에 todo / doing / done 컬럼 표시
  - 카드를 다른 컬럼으로 옮기면 상태 변경
  - 변경한 상태는 즉시 저장
- **기간 구조**
  - 일일: 할 일
  - 주간: 주간 계획 (CRUD)
  - 1년: 1년 목표 (CRUD)
- **구조 연결**
  - 할 일 → 주간 계획 (N:1)
  - 주간 계획 → 1년 목표 (N:1)
- **주간 진행률 자동 반영**
  - 계산식: `done 할 일 수 / 연결된 전체 할 일 수 × 100`
  - 할 일을 생성·삭제하거나 상태를 바꾸면 다시 계산
  - 연결된 할 일이 0개이면 0%

### P1 - 추가 기능

- 1년 목표 진행률을 연결된 주간 계획의 진행률로 집계
- 기간별 보기 전환 (일일 / 주간 / 1년)
- 1년 목표 → 주간 계획 → 할 일 계층 트리 보기
- 같은 컬럼 안에서 드래그 앤 드롭으로 순서 변경
